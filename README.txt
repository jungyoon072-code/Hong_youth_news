청년 뉴스 댓글 랭킹 설치·사용 안내
==================================================

제목에 '청년'이 들어간 네이버 뉴스 기사를 날짜별로 모아 댓글 많은 순으로 보여 주는 사이트입니다.
기사마다 댓글 수와 추천 스티커(공감백배·쏠쏠정보·흥미진진·분석탁월·후속강추) 수를 붙이고, 매시간 자동으로 다시 셉니다.

  - 비용: 0원 (GitHub 무료 기능 + 네이버 검색 API, 현재 한시적 무료)
  - 준비물: GitHub 계정, 네이버클라우드 계정(가입할 때 결제 카드 등록 필요)
  - 설치 시간: 15분 정도, 한 번만 하면 됩니다

동작 순서 (매시간 자동)
  GitHub Actions
    → 네이버 검색 API로 '청년' 기사 찾기
    → 제목에 '청년'이 있는 네이버 뉴스 기사만 남기기
    → 기사별 댓글 수·추천 스티커 수 세기
    → 날짜별 데이터 저장 → 사이트(GitHub Pages) 갱신


■ 설치
--------------------------------------------------

[1단계] 네이버 API 키 받기 (NAVER API HUB)

네이버 개발자센터의 '검색' API는 2026년 7월 31일부터 새로 신청할 수 없고, 네이버클라우드의 NAVER API HUB로 옮겨졌습니다. 그래서 개발자센터의 '사용 API' 목록에 '검색'이 보이지 않습니다. 키는 네이버클라우드에서 받습니다.

  1. 네이버클라우드 플랫폼(https://www.ncloud.com)에 회원가입하고 로그인합니다.
     - 지금은 한시적으로 무료지만 가입할 때 결제 카드 등록을 요구합니다. 무료 기간에는 월 한도에 닿으면 호출이 막힐 뿐 요금이 나가지 않고, 유료로 바뀌면 미리 공지한다고 안내하고 있습니다.
  2. 콘솔 메뉴에서 Services → Application Services → NAVER API HUB 로 들어갑니다.
  3. Subscription(이용 신청)에서 이용을 신청하고 약관에 동의합니다.
  4. Application → Application 등록 → API 목록에서 'NAVER 검색'의 '뉴스'를 고르고 다음 → Application 이름(예: 청년뉴스랭킹)을 넣고 등록합니다.
  5. 등록한 Application의 '인증 정보'에서 Client ID와 Client Secret을 메모해 둡니다.
     - 네이버클라우드 계정의 Access Key(ncp_iam_ 으로 시작)와는 다른 값입니다. 꼭 Application의 인증 정보를 쓰세요.

  ※ 2026년 7월 이전에 개발자센터에서 '검색' 키를 받아 두셨다면 그 키도 2027년 6월 30일까지는 그대로 동작합니다. 수집기가 새 방식(API HUB)을 먼저 시도하고, 안 되면 옛 방식으로 자동으로 바꿔 부릅니다.


[2단계] GitHub 저장소 만들기

  1. https://github.com 에 가입하거나 로그인합니다.
  2. 오른쪽 위 ＋ → New repository
  3. Repository name: 예) youth-news   (이 이름이 사이트 주소에 들어갑니다)
  4. Public 을 고릅니다. (무료 요금제에서 사이트를 열고 자동 실행을 제한 없이 쓰려면 공개 저장소여야 합니다)
  5. 나머지는 그대로 두고 Create repository


[3단계] 파일 올리기

  1. 받은 압축 파일을 풉니다. youth-news 폴더가 생깁니다.
  2. 방금 만든 저장소 화면에서 'uploading an existing file' 링크를 누릅니다.
  3. youth-news 폴더 안에 있는 것 전부(.github, docs, scripts, config.json, README.txt)를 끌어다 놓습니다.
     - Mac: .github 폴더는 숨김 폴더라 Finder에서 안 보일 수 있어요. Finder에서 Cmd + Shift + . 을 누르면 보입니다. 꼭 함께 올려 주세요.
  4. 아래쪽 Commit changes 를 누릅니다.
  5. 저장소 첫 화면에 .github, docs, scripts 폴더가 보이면 성공입니다.

  ※ .github 폴더만 빠졌다면: Add file → Create new file → 파일 이름 칸에 .github/workflows/update.yml 을 그대로 입력 → 압축 파일 속 같은 파일의 내용을 붙여 넣고 Commit changes.


[4단계] API 키 등록

  1. 저장소 Settings → Secrets and variables → Actions
  2. New repository secret → Name: NAVER_CLIENT_ID / Secret: 1단계 API HUB의 Client ID → Add secret
  3. 한 번 더 → Name: NAVER_CLIENT_SECRET / Secret: 1단계 API HUB의 Client Secret → Add secret

  키는 암호화되어 보관되고, 공개 저장소여도 다른 사람에게는 보이지 않습니다.


[5단계] 사이트 켜기

  1. 저장소 Settings → Pages
  2. Build and deployment → Source 를 'GitHub Actions'로 바꿉니다. (따로 저장 버튼은 없습니다)


[6단계] 첫 실행

  1. 저장소 위쪽 Actions 탭 → 왼쪽 '청년 뉴스 수집·배포'
  2. 오른쪽 Run workflow → 실행 방식 '수집' → Run workflow
  3. 2~5분 뒤 초록색 체크가 뜨면 끝입니다. 실행 기록을 열면 '사이트 배포' 칸에 주소가 나옵니다.
     주소 모양: https://<GitHub 아이디>.github.io/youth-news/
  4. 이제부터는 매시간 저절로 갱신됩니다.

  ※ 파일을 올린 직후 4·5단계를 하기 전에 정시 실행이 한 번 돌면 빨간 X(실패)가 하나 생길 수 있습니다. 설정을 마친 뒤 6단계를 하면 되니 신경 쓰지 않으셔도 됩니다.


■ 처음 며칠은
--------------------------------------------------

네이버 검색 API는 검색어마다 최근 1,000건까지만 거슬러 올라갈 수 있습니다. 그래서 첫 실행 때는 최근 하루이틀치가 주로 채워지고 그 이전 날짜는 일부만 들어옵니다. 그다음부터는 매시간 새 기사를 빠짐없이 쌓습니다.


■ 화면 쓰는 법
--------------------------------------------------

  - 날짜 탭: 오늘과 지난 6일. '최근 7일' 탭은 일주일치를 한꺼번에 순위로 보여 줍니다.
  - 키워드: 제목·언론사에서 찾습니다. 띄어 쓰면 모든 단어가 들어간 기사만 남깁니다. (예: 주거 월세)
  - 날짜 칸: 지난 날짜로 바로 갑니다. 이 사이트가 기록을 시작한 날부터 볼 수 있습니다.
  - 분야: '정치 3', '사회 10' 같은 글자를 누르면 그 분야만 봅니다.
  - 정렬: 댓글순 / 증가순(직전 갱신보다 댓글이 많이 늘어난 순, 지금 논쟁이 붙는 기사) / 반응순(추천 스티커 합계) / 최신순
  - 숫자: 댓글 수를 누르면 그 기사의 댓글 화면이 새 창으로 열립니다. 맨 오른쪽 +12 는 직전 갱신 대비 늘어난 댓글 수입니다.
  - CSV 저장: 지금 보이는 목록을 엑셀에서 열 수 있는 파일로 내려받습니다.
  - 링크 공유: 주소창 주소에 날짜·검색어·분야·정렬이 담겨 있어 그대로 복사해 보내면 같은 화면이 열립니다.


■ 설정 바꾸기 (config.json)
--------------------------------------------------

저장소에서 config.json → 연필 아이콘 → 고친 뒤 Commit changes. 다음 실행부터 반영되고, 바로 보고 싶으면 Actions에서 Run workflow 를 누르세요.

  - site_title: 사이트 제목
      기본값: "청년 뉴스 댓글 랭킹"
  - search_queries: 네이버에서 검색할 말. 많을수록 빠짐없이 모읍니다.
      기본값: 청년, 청년층, 청년 정책 등 10개
  - title_keywords: 제목에 이 중 하나라도 있어야 남깁니다.
      기본값: ["청년"]
  - exclude_title_keywords: 제목에 이 말이 있으면 뺍니다.
      기본값: []   (예: ["청년회의소"])
  - sections: 남길 분야. 비우면 전부.
      기본값: []   (예: ["정치", "경제", "사회"])
  - track_days: 댓글 수를 계속 다시 세는 기간(일). 날짜 탭 개수와 같습니다.
      기본값: 7

  분야 이름: 정치, 경제, 사회, 생활/문화, 세계, IT/과학, 오피니언, 기타

다른 주제로도 쓸 수 있습니다. 예를 들어 search_queries 를 ["저출생", "저출산"], title_keywords 를 ["저출생", "저출산"] 으로 바꾸면 저출생 기사 랭킹이 됩니다.


■ 갱신 주기
--------------------------------------------------

  - .github/workflows/update.yml 의 cron: "7 * * * *" 가 '매시간 7분'이라는 뜻입니다. 30분마다 돌리려면 "7,37 * * * *" 로 바꾸면 됩니다. GitHub 사정으로 몇 분에서 수십 분 늦게 도는 때가 있습니다.
  - 댓글 수는 기사 나이에 따라 다시 셉니다. 하루가 안 된 기사는 매번, 1~3일 된 기사는 3시간마다, 그보다 오래된 기사는 12시간마다. 7일이 지나면 마지막 숫자로 고정됩니다.


■ 문제가 생기면
--------------------------------------------------

  - 사이트 위쪽에 안내 띠가 뜹니다. 노란색은 일부 문제, 빨간색은 수집 실패, '마지막 갱신이 N시간 전'은 자동 실행이 멈춘 경우입니다.
  - Actions 탭에서 빨간 X가 붙은 실행 → '기사 수집' 단계를 열면 한국어로 이유가 적혀 있습니다.
  - 연결 점검: Actions → Run workflow → 실행 방식 '연결점검'. 기사 한 건으로 검색 → 기사 페이지 → 댓글 수 → 추천 스티커를 차례로 확인하고 결과를 로그에 그대로 보여 줍니다. 이 로그를 복사해 Claude에게 보여 주시면 원인을 찾아 고칠 수 있습니다.

증상별로 확인할 것

  - "네이버 API 키 인증에 실패"
      → Secrets 이름이 NAVER_CLIENT_ID, NAVER_CLIENT_SECRET 인지
      → 값이 API HUB Application의 Client ID·Secret인지 (계정 Access Key가 아님)
      → 값 앞뒤에 빈칸이 없는지
  - "네이버 API HUB 권한이 없습니다"
      → 네이버클라우드 콘솔 → NAVER API HUB → Application에 'NAVER 검색'의 '뉴스'가 선택되어 있는지
  - 사이트 주소가 404
      → Settings → Pages 의 Source 가 'GitHub Actions'인지, 첫 실행이 초록 체크인지
  - 댓글 수가 – 로 비어 있음
      → 네이버가 내부 방식을 바꿨을 수 있습니다 → 연결 점검
  - 자동 실행이 멈춤
      → Actions 탭에서 워크플로를 다시 켜기(Enable workflow)


■ 알아 두실 점
--------------------------------------------------

  - 기사 검색은 네이버 공식 검색 API(NAVER API HUB)를 씁니다. 현재 한시적 무료이고 하루 25,000회, 한 달 775,000회까지 부를 수 있습니다. 이 사이트는 한 시간에 수십 회 정도만 씁니다.
  - 2026년 9월 7일부터 바뀐 네이버 API 이용약관에 따라, 검색 API로 받은 결과를 AI에 넣거나 학습·평가에 쓰는 것, 제3자에게 넘기거나 파는 것, 결과를 보여 주는 페이지에 광고를 붙이는 것이 금지됩니다. CSV로 받은 목록도 같은 기준으로 다뤄 주세요.
  - 댓글 수·추천 스티커 수는 네이버 뉴스 화면이 내부적으로 쓰는 주소에서 읽습니다. 공식 API가 아니라서 네이버가 바꾸면 갑자기 안 될 수 있습니다. 요청 사이에 간격을 두어 부담을 줄였으니 개인·연구용 모니터링으로 쓰시길 권합니다.
  - 사이트는 공개 주소라 주소를 아는 사람은 누구나 볼 수 있습니다.
  - 모든 기록은 저장소의 docs/data/days/날짜.json 에 날짜별로 쌓여 연구용 원자료로도 쓸 수 있습니다. 데이터를 저장할 때마다 GitHub에 기록(커밋)이 하나씩 남는 것은 정상입니다.


■ 파일 구성
--------------------------------------------------

  .github/workflows/update.yml   매시간 실행 일정
  scripts/collect.py             수집기 (파이썬 기본 기능만 사용)
  config.json                    설정
  docs/index.html                사이트 화면
  docs/data/                     수집된 데이터 (자동으로 생깁니다)
  README.txt                     이 안내서

내 컴퓨터에서 직접 돌려 보려면(선택)

  NAVER_CLIENT_ID=... NAVER_CLIENT_SECRET=... python3 scripts/collect.py
  cd docs && python3 -m http.server 8000      (브라우저에서 http://localhost:8000)
